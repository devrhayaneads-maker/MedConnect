MedConnect

Escaneie o QR Code ou toque no botão para baixar o app (Android).

Baixar APK
  1. Baixe o arquivo medconnect.apk.
  2. Se o Android avisar sobre "fontes desconhecidas", toque em "Permitir" — o app não vem de uma loja, mas é seguro (projeto acadêmico).
  3. Abra o arquivo baixado para instalar.
